H(z), ecuación y realización

Definí tu sistema

Usá z^-1, z^-2, … y paréntesis para separar numerador y denominador.

Ejemplo de escritura(1 + 0.5*z^-1) / (1 - 0.8*z^-1 + 0.15*z^-2)

Se aceptan coma decimal, notación científica y términos repetidos. Solo potencias enteras de z⁻¹, hasta el nivel 8.

Índices entre 0 y 8. Los índices omitidos valen cero. Tocá un coeficiente para editarlo. “Realizar” reinicia las memorias en cero.

Términos de y[n]

Para y[n−k], k va de 1 a 8. El término y[n] se configura mediante a₀.

Ejemplo de escritura2*y[n] = x[n] + 0.5*x[n-1] + y[n-1] - 0.25*y[n-2]

El simulador reúne los términos y genera la forma directa I. No se admiten productos entre señales, adelantos ni términos independientes distintos de cero.

Agregá niveles en cada lado y escribí las ganancias directamente sobre las ramas del diagrama. Confirmá con Enter o al salir del campo.

Cómo usar el simulador

1. Elegí H(z), ecuación o dibujo para definir el sistema. Las otras dos representaciones se actualizan al aplicar los cambios.

2. Elegí forma directa I o II. En la II, las dos ramas comparten una cadena de retardos de la señal interna v[n]. Agregá o quitá niveles desde “Realización”.

3. Calculá una muestra y luego avanzá todos los retardos simultáneamente.

Cambiar el sistema reinicia la simulación con condiciones iniciales nulas. Los valores informativos muestran hasta dos decimales; los cálculos conservan su precisión.

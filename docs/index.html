Cómo leer los gráficos

El punto recorre z = ejω, desde −π hasta π. Cada vector parte de una raíz y termina en ese punto. Los arcos violetas miden su ángulo desde el semieje real positivo.

|H| = |K| · ∏ distancias a ceros / ∏ distancias a polos

Fase = arg(K) + ∑ ángulos de ceros − ∑ ángulos de polos

Se cuentan las multiplicidades y las raíces en el origen. Se cancelan sólo coincidencias exactas. En un cero sobre |z| = 1, el módulo es cero y la fase no está definida. La normalización busca el máximo numéricamente y refina las resonancias.
